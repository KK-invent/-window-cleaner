# 窗口清理（WindowCleaner）

本地运行的 macOS 原生窗口整理工具，使用 Swift、SwiftUI 和 AppKit 开发。

- **窗口与应用**：窗口缩略图总览，单击关闭窗口；下方应用图标用于正常退出应用。支持跨窗口区和应用栏统一框选，也可切换为先选再执行。
- **浏览器标签页**：独立页面管理 Chrome 系浏览器标签页，支持搜索、按窗口或网站分组、单击关闭和框选。网站图标从本机浏览器缓存只读获取。
- **操作反馈**：串行处理关闭请求，保留原应用确认框；区分已关闭、等待处理、已跳过和失败。不会强制退出目标应用。
- **界面**：无卡片外框的窗口预览、透明毛玻璃、进入和退出动画；总览期间隐藏系统程序坞，收起后恢复。

## 构建与运行

最低目标系统为 macOS 14；主要开发验证环境为 Apple Silicon、macOS 27.0.1、Swift 6.4。使用 Xcode 命令行工具直接编译，不依赖 SwiftPM。固定签名生成步骤使用 OpenSSL 3 的 `-legacy` 选项；无法生成证书时脚本会尝试退回临时签名。

```bash
git clone https://github.com/KK-invent/-window-cleaner.git window-cleaner
cd window-cleaner
bash scripts/build.sh
```

构建脚本默认将主应用安装到 `/Applications/窗口清理.app`，会替换该位置的已有版本；没有写入权限时输出到 `dist/窗口清理.app`。测试宿主位于 `dist/测试工具/`。

```bash
bash scripts/build.sh app       # 构建并安装主应用
bash scripts/build.sh testhost  # 构建专用测试应用
bash scripts/build.sh checks    # 运行无需系统权限的逻辑检查
```

双击应用后，按引导授予辅助功能和屏幕录制权限；浏览器标签页管理另需允许自动化控制浏览器。

## 签名与隐私

首次构建会在本机 `signing/` 中生成专用签名证书。保留该目录通常有助于更新后维持系统授权；不同机器会生成各自的证书，仍需各自授权。

**签名私钥、钥匙串密码、构建产物、运行日志和本机验证截图均不在仓库中。** `.gitignore` 已排除这些文件。请勿强制提交 `signing/`，也不要将它分享给他人。

应用不联网；窗口缩略图在内存中处理；浏览器图标从本机缓存读取。运行日志不记录窗口标题。仓库附带的技术记录是开发历史，部分路径及测试结果仅适用于原开发机器。

## 使用与验证

- [中文使用说明](使用说明.md)
- [技术说明、兼容范围与验证记录](技术说明与验证记录.md)
- 自检：右键 Dock 图标 → 运行自检，或双击 `运行自检.command`。自检使用专用测试窗口；浏览器检查会启动独立临时资料夹的 Chrome。

逻辑检查与真实界面测试是两类验证：逻辑检查通过不代表所有应用兼容。真实关闭、原生确认框及鼠标框选仍取决于系统授权和目标应用实现；详情以本机生成的自检报告为准。

## 目录

| 路径 | 内容 |
|---|---|
| `Sources/WindowCleaner/` | 总览、界面交互、缩略图、自检 |
| `Sources/WindowCleanerCore/` | 窗口匹配、关闭和退出、浏览器标签页与图标 |
| `Sources/CoreChecks/` | 模拟后端逻辑检查 |
| `Sources/WCTestHost/` | 专用测试窗口宿主 |
| `Tools/` | 开发用界面、内存和手势检查工具 |
| `scripts/` | 构建与图标生成脚本 |
